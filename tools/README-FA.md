# راهنمای مدیر — فید تبلیغات «بدون ضربدر» (نسخهٔ ۱.۱۱.۳۵، اصلاح ۱.۱۱.۳۶)

از این نسخه، تبلیغات صفحهٔ اصلی بادخزان **فقط با فید** کنترل می‌شود: کاربر
هیچ × و هیچ راهی برای پنهان‌کردن ندارد؛ حذف/ویرایش/افزودن فقط با تغییر همین
فایل انجام می‌شود و با هر همگام‌سازی، فهرست روی همهٔ کاربران **کامل جایگزین**
می‌شود.

فایل: `feed/main_ads.json` (+ امضای کنارش `feed/main_ads.json.sig`)

```json
{
  "sequence": 1,                       ← هر انتشار +۱ (ضد بازپخش؛ کوچک‌تر/مساوی رد می‌شود)
  "issuedAt": "2026-11-01T00:00:00Z",  ← تاریخ صدور (الزامی — گارد نصب تازه)
  "adsEnabled": true,                  ← کلید قطع اضطراری سراسری (false = همهٔ تبلیغ‌ها خاموش)
  "maxCacheDays": 7,                   ← کش قدیمی‌تر از این (روز) نمایش داده نمی‌شود (۰ تا ۳۰)
  "items": [
    {
      "id": "tile-1",                  ← یکتا
      "type": "tile",                  ← tile (کارت شبکه‌ای) یا banner (بنر تمام‌عرض)
      "enabled": true,
      "title": "ختم قرآن",             ← حداکثر ۴۰ کاراکتر
      "iconUrl": "https://…",          ← فقط tile — https یا data:image/jpeg|png|webp;base64
      "imageUrl": "https://…",         ← فقط banner — https یا data:image (جاسازی). نسبت هر تصویری مجاز است و تصویر هرگز بریده نمی‌شود (۱.۱۱.۳۷): عریض ~۳:۱ لبه‌به‌لبه پر می‌شود؛ عمودی/لوگو کامل و وسط‌چین تا ارتفاع ۲۸۰dp
      "badge": "جدید",                 ← اختیاری، حداکثر ۱۲ کاراکتر (پیش‌فرض قرمز)
      "targetType": "external",        ← external یا internal
      "target": "https://…",           ← لینک https، یا کلید داخلی
      "order": 1,                      ← ترتیب (کوچک‌تر جلوتر)
      "startAt": "2026-11-01T00:00:00Z", ← اختیاری
      "endAt":   "2026-12-01T00:00:00Z", ← اختیاری (بعد از آن خودکار حذف می‌شود)
      "minVersionCode": 0,             ← اختیاری — فقط در نسخه‌های بالاتر
      "description": "…"               ← اختیاری — متن TalkBack (حداکثر ۸۰)
    }
  ]
}
```

کلیدهای داخلی مجاز (`targetType: "internal"`):
`calendar` · `prayer` · `qibla` · `events` · `reminders` · `announcements` · `support` · `account`

## تصویر آیتم — دو راه (نسخهٔ ۱.۱۱.۳۶)

1. **URL https** — تصویر را هر جا میزبانی کنید (مثلاً پوشهٔ `docs/img/` همین
   مخزن؛ آدرس `https://raw.githubusercontent.com/…` هم مجاز است).
2. **جاسازی درون‌خطی (مثل اطلاعیه‌ها)** — `data:image/jpeg;base64,…` تا سقف
   ۴۰۰ هزار کاراکتر. از پنل مدیریت اپ این کار خودکار است: عکس گالری موقع انتشار
   فشرده (تا ۲۰۰ کیلوبایت JPEG) و داخل فید جاسازی می‌شود و اپ ۱.۱۱.۳۶ آن را
   محلی decode می‌کند (بدون هیچ درخواست شبکه‌ای). فقط سه فرمت رستری مجاز است؛
   svg/xml رد می‌شود.

⚠️ یادآوری مهم (اشتباه ۱.۱۱.۳۵ که «تبلیغ نمایش داده نمی‌شود» ساخت): در آن
نسخه عکس‌های گالری موقع انتشار بی‌صدا حذف می‌شد و فیدِ خالیِ `items: []`
منتشر می‌شد — از ۱.۱۱.۳۶ اگر هیچ بنری قابل انتشار نباشد، هیچ‌چیز منتشر
نمی‌شود و دلیل هر بنر ردشده در پیام پنل اعلام می‌شود.

## چطور تبلیغ اضافه کنم؟

**از گوشی (ساده‌ترین راه):** پنل مدیریت → بنر را با «انتخاب تصویر از گالری»
بسازید → دکمهٔ «انتشار فید تبلیغات (sequence +۱)» → چند ثانیه بعد امضای CI
آماده می‌شود → برنامه را ببندید و دوباره باز کنید؛ بنر زیر تقویم می‌آید
(بستن پنل خودش همگام‌سازی فوری می‌زند).

**از رایانه:**

1. تصویر را جایی با لینک https میزبانی کنید (مثلاً همین مخزن: پوشهٔ `docs/img/`
   یا هر هاست — آدرس `https://raw.githubusercontent.com/…` هم مجاز است)
   یا تصویر را data URI جاسازی کنید.
2. آیتم جدید را به `items` اضافه کنید (یک بلوک JSON مثل بالا؛ `tile` برای
   کارت‌های شبکه‌ای، `banner` برای بنر تصویری تمام‌عرض).
3. اعتبارسنجی + افزایش sequence + امضا:
   ```bash
   export ADS_FEED_KEY="$(cat مسیر/کلید-خصوصی.b64)"   # فقط نزد شما
   python3 tools/ads_feed.py
   ```
4. `git add feed/main_ads.json*` و commit و push — کاربران در باز شدن بعدی اپ
   (یا حداکثر تیک شبانه) می‌گیرند.

## چطور حذف کنم؟

آیتم را از `items` بردارید (یا `enabled: false` بگذارید)، دوباره
`python3 tools/ads_feed.py` بزنید و push کنید. چون sequence بالا می‌رود،
اپ آن را می‌پذیرد و آیتم در همان همگام‌سازی بعدی از همهٔ کاربران حذف می‌شود.

نکتهٔ امنیتی مهم: فیدِ قدیمیِ امضاشده دوباره منتشر شود (بازپخش)، اپ آن را با
«sequence کوچک‌تر یا مساوی» رد می‌کند — یعنی حتی اگر کسی فایل قدیمی مخزن را
برگرداند، تبلیغ حذف‌شده برنمی‌گردد.

## چطور امضا کنم؟ (سریع)

- امضای خودکار: هر push که این فایل را تغییر دهد، وورکفلوی «Sign feed files»
  امضای تازه می‌سازد (کلید در Secret مخزن).
- امضای دستی از رایانه: `python3 tools/ads_feed.py` (بالا) یا فقط امضا:
  ```bash
  FEED_SIGNING_KEY="$(cat کلید-خصوصی.b64)" python3 scripts/sign_feed.py
  ```

## کلید کجاست و چطور بچرخانم؟ (key rotation)

- **کلید خصوصی فقط دو جا**: Secret مخزن گیت‌هاب (`FEED_SIGNING_KEY`) و رایانهٔ
  شخصی شما. **هرگز** داخل مخزن/اپ/اسکرین‌شات نباشد — `.gitignore` جلوی
  `*.b64` و `*.private.b64` و `tools/*.key` را می‌گیرد، ولی حواستان باشد.
- اپ فقط کلیدهای **عمومی** را می‌شناسد (FeedSecurity): کلید اصلی
  `lpVtz80e…` و کلید چرخش ۲۰۲۶-۱۱-۰۱ `Z5mIWsYE…` — هر دو معتبرند.
- **چرخش**: کلید Ed25519 تازه بسازید:
  ```bash
  python3 -c "import base64,os; from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey; k=Ed25519PrivateKey.generate(); print(base64.b64encode(k.private_bytes(encoding=__import__('cryptography.hazmat.primitives.serialization',fromlist=['Encoding']).Encoding.Raw,format=__import__('cryptography.hazmat.primitives.serialization',fromlist=['PrivateFormat']).PrivateFormat.Raw)).decode())" > کلید-جدید.b64
  ```
  1. Secret مخزن `FEED_SIGNING_KEY` را با کلید جدید به‌روز کنید.
  2. کلید عمومی جدید را برای توسعه‌دهنده بفرستید تا به `FeedSecurity` اضافه شود
     و با یک نسخهٔ جدید اپ منتشر شود (کلید عمومی راز نیست).
  3. از همان لحظه امضاهای CI با کلید جدید معتبرند؛ اپ‌های نسخهٔ قبلی هم تا
     وقتی کلید قدیمی در FeedSecurity هست کار می‌کنند (پذیرش دو کلید = دورهٔ گذار).
- اگر کلید خصوصی لو رفت: فوراً همان مراحل چرخش را انجام دهید و `adsEnabled`
  را موقتاً `false` کنید (قطع اضطراری بدون انتشار نسخهٔ جدید).

## اعتبارسنجی خودکار در CI

وورکفلوی «Sign feed files» پیش از امضا، `tools/ads_feed.py --validate` را
اجرا می‌کند: اگر schema/https/تاریخ‌ها خراب باشند، push قرمز می‌شود و امضای
خراب منتشر نمی‌شود. برای آزمایش محلی: `python3 tools/ads_feed.py --validate`

## پرسش‌های رایج

- **بنر قبلی من (سوپرمارکت دانشور) کجا رفت؟** عکس آن به‌صورت data URI داخل
  خوراک بود؛ در ۱.۱۱.۳۵ موقتاً فقط https پذیرفته می‌شد. از ۱.۱۱.۳۶ data URI
  دوباره مجاز است — با پنل (عکس گالری) یا فایل، همان بنر را دوباره بسازید.
- **از پنل مدیریت اپ هم می‌شود؟** بله — دکمهٔ «انتشار فید تبلیغات (sequence +۱)»
  در پنل، همین فرمت را از پیش‌نویس بنرهای پنل می‌سازد و منتشر می‌کند؛ عکس گالری
  خودکار جاسازی می‌شود (کارت‌های tile فعلاً فقط از فایل قابل افزودن‌اند).
- **چرا تبلیغی که می‌گذارم نمایش داده نمی‌شود؟** سه دلیل رایج: ۱) در نسخهٔ
  ۱.۱۱.۳۵ عکس گالری منتشر نمی‌شد (اصلاح شد — اپ را ۱.۱۱.۳۶+ و پنل را هم همان
  نسخه کنید و دوباره منتشر کنید) ۲) امضای هنوز ساخته نشده — چند ثانیه بعد از
  انتشار صبر کنید و برنامه را ببندید/باز کنید ۳) در پنل «بررسی فید تبلیغات
  کاربران» را بزنید؛ اگر «خالی است (۰ آیتم)» گفت، یعنی فید واقعاً خالی است.
- **حداکثر چند تبلیغ؟** تا ۱۲ آیتم در فید؛ سقف نمایش با خود شماست (order).
