== Calendar algorithm ==
Jalali calendar conversion is based on the widely used jalaali-js algorithm
(Kazimierz M. Borkowski's Persian calendar arithmetic), reimplemented in Kotlin.

== Prayer times ==
Prayer time calculation is based on the standard PrayTimes algorithm
(https://praytimes.org) with the official Tehran Institute of Geophysics
parameters (Fajr 17.7, Isha 14, Maghrib 4.5 degrees).
