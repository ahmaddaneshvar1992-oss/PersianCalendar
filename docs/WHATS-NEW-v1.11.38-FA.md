# تازه‌های نسخهٔ ۱.۱۱.۳۸ (versionCode ۵۰)

## رفع دو مشکل تبلیغات: «خیلی دیر بالا می‌آید» و «حذف نمی‌شود»

گزارش شما بررسی شد؛ هر دو علت پیدا شد و رفع شد:

**۱. حذف تبلیغ کار نمی‌کرد (نه برای شما، نه برای کاربران)**

محافظ نسخهٔ ۱.۱۱.۳۶ — که برای جلوگیری از فیدِ خالیِ ناخواسته گذاشته شده بود —
فیدِ بدون آیتم را همیشه رد می‌کرد. اما «فید بدون آیتم» دقیقاً همان راهِ
**حذف عمدی** تبلیغ‌هاست! نتیجه: وقتی بنر را از فهرست پاک می‌کردید و دکمهٔ
انتشار را می‌زدید، انتشار رد می‌شد، فید سرور همان قبلی می‌ماند و تبلیغ برای
هیچ‌کس حذف نمی‌شد.

**اصلاح:** حالا سه حالت از هم تفکیک می‌شود:

- فهرست بنرها **خالی یا خاموش** → فید خالی منتشر می‌شود = «حذف همهٔ تبلیغ‌ها
  برای همه» (پیام پنل صریح می‌گوید حذف شد) ✓
- بنرهایی در فهرست هست ولی **هیچ‌کدام قابل انتشار نیست** (تصویر خراب و…)
  → هیچ‌چیز منتشر نمی‌شود و دلیل هر بنر اعلام می‌شود (همان حفاظ قبلی) ✓
- دست‌کم یک بنر سالم → فید با همان آیتم‌ها منتشر می‌شود ✓

**۲. تبلیغ تازه خیلی دیر بالا می‌آمد**

بعد از انتشار، امضای CI حدود ۱ تا ۳ دقیقه بعد آماده می‌شود؛ اما بستن پنل فقط
**یک بار** همگام‌سازی می‌زد که معمولاً زودتر از آماده‌شدن امضا بود → مردود
می‌شد و تبلیغ تا همگام‌سازی بعدی (باز شدن دوباره یا ۱۰ دقیقه) نمی‌آمد.

**اصلاح:** بستن پنل حالا یک حلقهٔ بازآزمون کوتاه راه می‌اندازد: هر ۴۰ ثانیه،
حداکثر ۱۲ بار (~۸ دقیقه)؛ به‌محض آماده‌شدن امضا و پذیرفته‌شدن فید، تبلیغ تازه
(یا حذف) **همان لحظه** روی صفحه اعمال می‌شود — بدون بستن و باز کردن برنامه.

## بعد از به‌روزرسانی چه کنید؟

1. هر دو دستگاه (پنل و نمایش) را به ۱.۱۱.۳۸ به‌روز کنید.
2. برای حذف: بنر را از فهرست پنل پاک یا خاموش کنید → «انتشار فید تبلیغات»
   را بزنید → پنل را ببندید → تا چند دقیقه دیگر از همهٔ دستگاه‌ها (از جمله
   گوشی خودتان) حذف می‌شود.
3. برای افزودن: بنر را بسازید → انتشار → بستن پنل → تا چند دقیقه دیگر می‌آید.

امنیت دست‌نخورده ماند: امضای Ed25519، ضد rollback با sequence، فید خالیِ
امضاشده هم مثل بقیه امضا و تأیید می‌شود؛ بازپخش فید قدیمی همچنان رد می‌شود.
