# راهنمای انتشار محتوا (بعد از ۱.۱۱.۳۰) — بادخزان

از نسخهٔ ۱.۱۱.۳۰ توکن گیت‌هاب و پنل مدیریت از **نسخهٔ عمومی** حذف شده‌اند. محتوای کاربران (اطلاعیه و بنر) حالا سه راه انتشار دارد. در همهٔ راه‌ها امضای Ed25519 **خودکار** ساخته می‌شود.

---

## قدم یک‌بار برای همیشه: Secret امضا آماده است

کلید خصوصی امضا در Secret مخزن با نام `FEED_SIGNING_KEY` ذخیره شده است (Settings ← Secrets and variables ← Actions). وورکفلوی «Sign feed files (Ed25519)» هر تغییر خوراک را خودکار امضا می‌کند. کلید خصوصی پشتیبان هم جداگانه برای شما در پوشهٔ دانلود است — آن را فقط روی رایانهٔ خودتان نگه دارید.

---

## راه ۱ — ویرایش در وب گیت‌هاب (ساده‌ترین)

1. در گیت‌هاب فایل `feed/announcements.json` یا `feed/main_ads.json` را باز کنید و دکمهٔ مداد (Edit) را بزنید.
2. محتوای دلخواه را بگذارید و Commit بزنید.
3. چند ثانیه بعد وورکفلوی امضا اجرا می‌شود، فایل `.sig` را می‌سازد و کامیت می‌کند — کاری لازم ندارید.
4. اپ کاربران در باز شدن بعدی یا تیک نیمه‌شب آن را می‌گیرند.

نمونهٔ قالب اطلاعیه:

```json
[
  {
    "id": 1730000001000,
    "type": "news",
    "title": "عنوان خبر",
    "body": "متن اطلاعیه",
    "link": "https://example.com",
    "image": "",
    "on": true,
    "at": 1730000001000
  }
]
```

* حذف همگانی: فایل را خالی کنید یعنی `[]` بگذارید و Commit بزنید — اپ‌ها اطلاعیه‌های قبلی را از دستگاه کاربران برمی‌دارند (از ۱.۱۱.۲۶).

## راه ۲ — انتشار از رایانه

```bash
# ۱) فایل feed/announcements.json یا feed/main_ads.json را ویرایش کنید
# ۲) امضا:
FEED_SIGNING_KEY="$(cat feed-ed25519-private.b64)" python3 scripts/sign_feed.py
# ۳) ارسال:
git add feed/
git commit -m "اطلاعیه‌های بادخزان — انتشار"
git push
```

## راه ۳ — پنل مدیریت روی گوشی (نسخهٔ شخصی شما)

APK فلاور **admin** (پنل کامل + توکن انتشار) در Actions همین مخزن به‌صورت artifact خصوصی به نام `PersianCalendar-admin-apk` ساخته می‌شود — وارد Release عمومی نمی‌شود. آن را دانلود و نصب کنید؛ رمز پنل و توکن قبلی‌تان همان‌جا می‌ماند (همان امضا، همان دیتا).

- بعد از «انتشار برای کاربران»، اپ به‌طور خودکار وورکفلوی امضا را راه می‌اندازد؛ اگر توکن اجازهٔ Actions نداشته باشد، پیام راهنما می‌دهد.
- توکن تازه: Fine-grained با دسترسی **Contents: Read and write** و **Actions: Read and write** فقط برای مخزن PersianCalendar و با انقضای کوتاه.

---

## سرور شخصی (feedBaseUrl)

اگر `feedBaseUrl` را در `feed/config.json` پر کنید، اپ اول از سرور شما می‌خواند. سرور شما باید **همان مسیرها را کامل آینه کند** — یعنی `/feed/announcements.json` **و** `/feed/announcements.json.sig` و همین برای بنرها و config. اگر فایل `.sig` روی سرور نباشد، آن منبع رد و خودکار به گیت‌هاب برمی‌گردیم (چیزی خراب نمی‌شود، فقط منبع صفر عملاً خالی است). ساده‌ترین راه: کرون‌جاب rsync پوشهٔ `feed/` مخزن به سرور.

## نکتهٔ امنیتی مهم (باقی‌مانده از بازرسی)

- **توکن قبلی گوشی را همین حالا Revoke کنید** (Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Delete/Revoke).
- کلید امضای release برنامه (`signing/badkhan-release.jks` + رمز آن) از قبل داخل تاریخچهٔ مخزن عمومی است — یعنی هرکس به مخزن دسترسی بخواند می‌تواند APK هم‌امضا بسازد. این مشکل از ۱.۱۱.۳۰ جدا است و دو راه‌حل دارد: (الف) پذیرش ریسک + محافظت از دسترسی مخزن (2FA، بررسی اعضا)، (ب) چرخش کلید امضا در یک نسخهٔ برنامه‌ریزی‌شده که در آن کاربران یک‌بار نصب تازه می‌کنند — تصمیم با شماست.
