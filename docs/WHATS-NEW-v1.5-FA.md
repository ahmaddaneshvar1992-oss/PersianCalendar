# تازه‌های نسخه ۱.۵.۰ — منوی سه‌نقطه، پشتیبانی و بنرهای نامحدود

## ۱) منوی سه‌نقطه سمت چپ (⋮) به‌جای تب‌های بالایی

مطابق درخواست، همه منوها داخل یک منوی سه‌نقطه در **سمت چپ نوار بالا** قرار گرفتند.
با لمس ⋮ این گزینه‌ها باز می‌شوند:

- **تقویم** (صفحه اصلی)
- **اوقات شرعی**
- **قبله‌نما**
- **رویدادها**
- **تنظیمات**
- **پشتیبانی** (جدید)
- **پنل مدیریت تبلیغات**

نوار عنوان بالای صفحه هم نام صفحه فعلی را نشان می‌دهد.

## ۲) بخش پشتیبانی — پیام به مدیر

کاربر می‌تواند درخواست **تبلیغ**، گزارش **مشکل** یا **پیشنهاد** خود را برای شما بفرستد:

- فرم پیام: نوع پیام + نام + راه پاسخ‌گویی (ایمیل/شماره) + متن
- پیام‌ها در **صندوق پشتیبانی پنل مدیریت** ذخیره و نمایش داده می‌شوند (با دکمه حذف)
- دکمه **«ارسال با ایمیل»**: برنامه ایمیل با متن آماده باز می‌شود
- آدرس ایمیل مدیر در فایل `SupportBox.kt` → ثابت `ADMIN_EMAIL` — **پیش از انتشار عوضش کنید**

> ذخیره‌سازی فعلاً محلی است (filesDir). اگر می‌خواهید پیام‌ها از همه گوشی‌ها به شما برسند،
> در نسخه بعد می‌توان یک API ساده (مثلاً Google Form یا سرور خودتان) اضافه کرد.

## ۳) بنرهای تبلیغ — چندین تبلیغ، بدون محدودیت

تا نسخه قبل حداکثر ۳ بنر داشتید؛ حالا **هر تعداد بنر** می‌توانید اضافه کنید:

- پنل مدیریت ← بخش «بنرهای تصویری چرخشی» ← دکمه **«+ افزودن بنر جدید»**
- هر بنر: عکس + لینک اختصاصی + کلید روشن/خاموش + حذف
- بنرهای روشن به‌صورت چرخشی (هر ۶ ثانیه) در نوار پایین — به سبک کارت — نمایش داده می‌شوند
- بنرهای نسخه‌های قبل (۳ اسلات) **به‌صورت خودکار** به فهرست جدید منتقل می‌شوند
- اگر هیچ بنری فعال نباشد، فضای AdMob نمایش داده می‌شود

## ۴) اوقات شرعی کارتی مطابق عکس

- نوار سبز **«نزدیک‌ترین وقت شرعی»** در بالای فهرست اوقات + **شمارش معکوس** («۳ ساعت و ۵۴ دقیقه»)
- سطر وقتِ بعدی با رنگ تأکید مشخص می‌شود

## تغییرات فنی

- `SupportScreen.kt` و `SupportBox.kt` (جدید): فرم پشتیبانی + ذخیره JSON در filesDir
- `MainScreen`: TopAppBar با DropdownMenu سه‌نقطه؛ صفحه‌ها با selectedTab + supportVisible
- `AdminScreen`: مدیریت فهرست بنرها (JSON در DataStore: `banner_list_json`) + صندوق پشتیبانی + آمار پیام‌ها
- `Common.BannerAd`: چرخش از فهرست بنرها (بدون محدودیت) با مهاجرت خودکار اسلات‌های قدیمی
- `SettingsRepository`: کلید جدید `banner_list_json` + `BannerEntry`/`bannerEntries()`
- `PrayerScreen`: نوار نزدیک‌ترین وقت شرعی + شمارش معکوس
- versionCode 6 / versionName 1.5.0

## چک‌لیست پیش از انتشار

1. `ADMIN_EMAIL` در SupportBox.kt را به ایمیل خودتان تغییر دهید.
2. رمز پنل مدیریت را از حالت پیش‌فرض (۱۲۳۴) به یک رمز حرف+عددی تغییر دهید.
3. حالت آزمایشی AdMob را خاموش و شناسه‌های واقعی را ذخیره کنید.
4. اگر پیام‌های پشتیبانی باید از سرور بگذرند، API ارسال را اضافه کنید (فعلاً محلی است).
